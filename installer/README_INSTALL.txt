AnyCompare — Comparador de Pastas, Textos, Tabelas, Imagens, Hexadecimal, Versões, Registro e Mídia
====================================================================================================

Menu de Contexto do Windows Explorer:
- Selecione 2 arquivos ou 2 pastas -> botão direito -> "Comparar" (abre diretamente no AnyCompare).
- Selecione 1 arquivo ou 1 pasta -> botão direito -> "Selecionar arquivo/pasta esquerdo para comparar";
  depois clique com o botão direito em outro item -> "Comparar com <nome>".

Nota sobre o menu de 1º nível do Windows 11:
- O menu clássico ("Mostrar mais opções" / Windows 10) é ativado automaticamente sem certificado.
- O menu moderno de 1º nível do Windows 11 é ativado automaticamente se:
  (a) o pacote AnyCompareShellEx.msix foi assinado com um certificado confiável na máquina, OU
  (b) o Modo de Desenvolvedor do Windows 11 está ativado (Configurações -> Sistema -> Para desenvolvedores).
- Consulte %LOCALAPPDATA%\AnyCompare\shellex_install.log para ver o status do registro.
